# Данные

Циферблаты являются ресурсными WFF-пакетами (hasCode=false), без собственного сетевого кода. Показания шагов, заряда и назначенных complications предоставляет Wear OS. Отдельный поставщик тревоги обрабатывает геолокацию и сетевые данные по собственным правилам. Ключи подписи исключены из публичных исходников.

# Premium Watch Faces — Galaxy Watch 8 Classic

Три самостоятельных циферблата в Watch Face Format 4 для Wear OS 6 / API 36. У каждого свой package ID, поэтому они устанавливаются и выбираются независимо.

| Модуль | Package ID | Версия | Характер |
|---|---|---:|---|
| `watchface` | `com.emeraldvault.watchface` | 1.3.0 | Emerald Vault — бархатный изумруд и шампанское золото |
| `obsidian` | `com.obsidianprism.watchface` | 1.2.0 | Obsidian Prism — гранёный обсидиан и платина |
| `sapphire` | `com.sapphireflow.watchface` | 1.2.0 | Sapphire Flow — глубокое синее стекло и крупное цифровое время |

## Реализовано

- Manrope Light и SemiBold встроены в APK, поэтому Wear OS не заменяет выбранный шрифт системным.
- Emerald и Obsidian используют два одинаковых овала 150 × 88 для шагов и заряда; цифры центрированы в фиксированных областях.
- Верхний круг сохранён и показывает только иконку назначенного приложения/источника.
- Статус тревоги — только яркая точка: зелёная, красная или янтарная. Она рисуется поверх стрелок; зона 56 × 56 остаётся нажимаемой.
- В активном режиме работает 27-кадровый WebP-блик, повторяющийся при видимом циферблате. Дополнительно фон реагирует на наклон часов через акселерометр.
- Sapphire Flow также использует плавно «дышащий» разделитель времени.
- В AOD динамика и второстепенные декоративные слои отключаются.
- Фон расширен до 466 × 466 и обрезается экраном 450 × 450: чёрной щели между циферблатом и корпусом нет.
- Нет пульса, калорий, восхода или заката.

## Тревога

Данные поставляет `AlarmComplicationService` приложения `com.sasha.tryvohaporuch`:

- `0.0` — спокойно, зелёная точка;
- `0.5` — неизвестно или данные устарели, янтарная точка;
- `1.0` — тревога, красная точка с пульсирующим ореолом.

Нажатие по точке открывает подробности в приложении.

## Сборка

```bash
./build-all-apks.sh
```

Скрипт использует `ANDROID_SDK_ROOT`, а при его отсутствии автоматически находит SDK рядом с рабочей папкой. Готовые подписанные APK появляются в `release/`.

## Установка обновлений

```bash
adb install -r release/EmeraldVaultWatchFace-1.3.0.apk
adb install -r release/ObsidianPrismWatchFace-1.2.0.apk
adb install -r release/SapphireFlowWatchFace-1.2.0.apk
```

Все три обновления подписаны тем же ключом, что и предыдущие сборки; удалять старые версии не требуется.
